*Strategie Project Kaggle : 
- Dans la partie "Data Cleaning" Faire en sorte que la base train soit le plus proche possible de la base test. 
- Lorqu'on détecte une anomalie dans la base train, verifier si c'est le cas dans la base test avant de supprimer/corriger les observations. (exemple : si on detecte une anomalie dans la base train, verifier si c'est le cas dans la base test. Si l'anomalie est seulement présente dans la base train et non dans le test, alors on peut supprimer/modifier l'observation de la base train. Si ce n'est pas le cas, alors on ne touche pas à l'observation de la base train car ce n'est finalement pas une anomalie).
